# Experimental methodology

The settings and metrics below describe the verified `energy_public_v1` release candidate. They are retained unchanged for the source-only first release, which excludes the fitted bundle and generated evaluation JSON. See [recorded results](evaluation/release-candidate-results.md) and [reproduction instructions](reproducibility.md).

The target is next completed-session **Energy (kWh)** at a known station, using 24 consecutive completed-session histories. Histories are ordered by recorded End Date, with local source-order tie breaking. Invalid public measurements break histories; they are not skipped or imputed. Future duration and equipment fields are not input features or target eligibility requirements.

Source count: 259,415 rows. Timestamp quantiles at 70% and 85% define chronological targets. Cutoffs: `2018-10-07 15:52:12` and `2019-08-13 20:30:36`. Window counts: training 179,769, validation 38,906, test 38,807 (69.818%, 15.110%, 15.072%). Feature/target scalers and port/plug vocabularies use complete training-period rows; the station vocabulary uses the institutional registry. Historical Energy is an input and the next-session Energy is explicitly the target, with a dedicated target scaler.

Training: CPU, four threads, deterministic PyTorch algorithms, seed 42 for Python/NumPy/PyTorch; Adam learning rate 0.001; batch size 256; scaled MSE; gradient norm clipping at 1.0; at most 20 epochs with patience five. Eighteen epochs completed; validation selected epoch 13. Test scores were computed after model selection. The locally retained report contains exact history, package versions and dataset/source hashes; it is excluded from the first public commit and regenerated by training.

Model: input dimension 10, sequence length 24, embedding dimension 64, four attention heads, dropout 0.1, sinusoidal positions, one encoder attention/residual/normalization block and one decoder cross-attention/residual/normalization block, with scalar projection from the final position. Attention is dense. The historical class name `ProbSparseAttention` does not make the implementation sparse. No encoder distillation or equivalence to the associated IEEE paper is claimed.

Persistence predicts the last observed Energy. Station mean predicts complete-training-period mean Energy for that station, with a global training mean fallback (zero test fallbacks in the saved run). Public model MAE/RMSE: 5.87175854569893 / 8.607393349984621 kWh. Persistence: 8.126241477053108 / 11.888868459709448. Station mean: 5.801776442521896 / 8.707518861819395. Station mean wins MAE; the neural model wins RMSE.

Adjacent windows overlap; newly completed test sessions may become histories for subsequent predictions. This is rolling one-session forecasting, not fixed-origin multi-step forecasting. The recorded optional matched-cohort report compares the frozen prior internal model and public model on 18,336 shared test windows; their feature sets and training cohorts differ, so it is not a controlled ablation. No internal weights or histories are distributed.

Limitations: one seed, known stations only, naive End Date wall-clock ordering and cyclic time features, no timestamp input to independently validate request chronology, no differential privacy guarantee, and potential linkage of exact operational histories if users disclose them. No real histories are exported in this repository.
